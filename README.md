# Celebria – Celebrate Moments

*Платформа за организиране на събития с ИИ асистент.*

**Celebria** е уеб приложение за организиране на сватби, рождени дни, кръщенета и други събития. Потребителите могат да добавят, разглеждат, редактират и изтриват събития, както и да ги търсят по вид, статус, дата и други критерии.

Курсов проект по **Софтуерни технологии 2**, ПУ „Паисий Хилендарски“, ФМИ, 2026/2027.

## Технологии и интеграции

Приложението е разработено с C#, ASP.NET Core MVC (.NET 8), Razor Views, HTML, CSS, JavaScript и Bootstrap. За съхранение на информацията за събитията и потребителите се използва SQLite база данни.

Celebria е интегрирана с три външни услуги:

Google Gemini API — позволява интелигентно търсене на събития чрез въпроси на естествен език. ИИ моделът генерира структуриран JSON, който се валидира и преобразува в SQL заявка.

Google Maps — визуализира местоположението на събитията върху карта.

OpenWeather API — предоставя информация за текущите метеорологични условия на мястото на събитието.

## Архитектура и функционалности

Проектът следва MVC (Model-View-Controller) архитектура, като кодът е организиран в отделни слоеве — Models, Views, Controllers, Data и Services.

Основните функционалности включват:

CRUD операции за управление на събития.

Регистрация, вход и изход от потребителски профил.

Потребителски роли Admin и User, с различни права за достъп.

Административен панел за управление на потребителите.

Стандартно търсене и интелигентно търсене чрез ИИ.

Визуализация на местоположение и метеорологична информация.

В реализацията са приложени Design Patterns Singleton, Adapter/Facade и Interpreter, които подпомагат организацията на кода, повторното използване на компонентите и комуникацията с външни услуги.

Проектът включва и автоматизирани тестове с xUnit за проверка на основните функционалности, бизнес логиката и работата с базата данни.
