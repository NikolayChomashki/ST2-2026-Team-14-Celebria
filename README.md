# Celebria – Celebrate Moments

*Платформа за организиране на събития с ИИ асистент.*

**Celebria** е уеб платформа за агенции, които организират събития: сватби, кръщенета, рождени дни, фирмени партита, балове и конференции. Организаторът поддържа списък със събития и клиенти и ги филтрира. В следващите етапи ще има и ИИ асистент, който предлага програма, бюджет и идеи за декорация.

Курсов проект по **Софтуерни технологии 2**, ПУ „Паисий Хилендарски“, ФМИ, 2026/2027.

## Седмица 1: какво е готово

- [x] **INSERT.** Формата `Events/Create` добавя събитие в таблица `Events`. Има валидация в браузъра (jQuery Validation) и на сървъра (DataAnnotations, `[KnownEventType]`, дата не в миналото).
- [x] **SELECT с филтър.** На `Events/Index` събитията се филтрират по текст (наименование, клиент, място), тип, статус и период от/до. Филтрирането се прави в SQL (`WHERE`), не в паметта. Критериите стоят в адреса (`/Events?type=wedding&status=Confirmed`), така че резултатът може да се сподели. Има и бързи филтри по тип.
- [x] **Singleton Design Pattern**, в два варианта.
- [x] Unit и интеграционни тестове (xUnit).

## Седмица 2: какво е готово

- [x] **UPDATE.** `Events/Edit/{id}` редактира събитие със същата форма и валидация като при добавяне. Датата може да е в миналото, за да може вече проведено събитие да се отбележи като „Проведено“. Търсенето намира събитието по новото име.
- [x] **DELETE.** `Events/Delete/{id}` показва страница за потвърждение. Изтриването става само чрез POST с anti-forgery token, така че обикновен линк не може да изтрие нищо.
- [x] Бутони „Редакция“ и „Изтрий“ в списъка и в детайлите на събитието.
- [x] **Карта (Google Maps).** В детайлите се показва карта на полето „Място“ и връзка „Отвори в Google Maps“.
- [x] **Време (OpenWeather).** В детайлите се показва текущото време на мястото: температура, описание, влажност, вятър и налягане. Градът се взима от частта след последната запетая (напр. „Хотел „Империал“, **Пловдив**“). Резултатът се пази 10 минути в кеша.
- [x] **Нов дизайн.** Розова палитра, начален банер, карти и цветни етикети за статуса.
- [x] **Design patterns:** Repository (`IEventDatabase`), Factory Method (`Open()` и `Map()`), Options (`ExternalApisOptions`), Facade и Strategy (`IWeatherService`), Result object (`WeatherResult`), Cache-Aside и Chain/Fallback (търсене на мястото: „град,BG“ → „град“ → цялото място).
- [x] Тестове за UPDATE, DELETE и за заявките към картата и времето.

### Ключове за картата и времето

Ключовете не са качени в хранилището. Сложете ги в `Celebria/appsettings.json`, секция `ExternalApis`, или по-добре в **Manage User Secrets** във Visual Studio:

| Настройка | Задължителна? | Как се получава |
|---|---|---|
| `OpenWeatherApiKey` | да, за времето | безплатна регистрация на openweathermap.org → „My API keys“ (активира се до около 2 часа) |
| `GoogleMapsApiKey` | не | Google Cloud Console → Maps Embed API. Без ключ картата пак се показва. |

Без ключ за OpenWeather приложението работи, но вместо времето показва съобщение как да се добави ключът.
