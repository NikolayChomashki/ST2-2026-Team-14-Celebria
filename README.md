# Celebria – Celebrate Moments

*Платформа за организиране на събития с ИИ асистент.*

**Celebria** е уеб приложение за организиране на сватби, рождени дни, кръщенета и други събития. Потребителите могат да добавят, разглеждат, редактират и изтриват събития, както и да ги търсят по вид, статус, дата и други критерии.

Курсов проект по **Софтуерни технологии 2**, ПУ „Паисий Хилендарски“, ФМИ, 2026/2027.

## Технологии и интеграции
Приложението е разработено с C#, ASP.NET Core MVC (.NET 8), Razor Views, HTML, CSS, JavaScript и Bootstrap. Използва SQLite за съхранение на събития и потребители.

Свързано е с три външни услуги:
- Google Gemini API — търсене на събития чрез въпроси на естествен език. Отговорът на модела се преобразува във валидирана SQL заявка.
- Google Maps — показване на местоположението на събитие.
- OpenWeather API — информация за текущото време на мястото на събитието.

  
## Архитектура и функционалности
Проектът използва MVC архитектура, като кодът е разделен на Models, Views, Controllers, Data и Services. Реализирани са CRUD операции, регистрация и вход, потребителски роли и административен панел.

Използвани са Design Patterns като Singleton, Adapter/Facade и Interpreter. Има и автоматизирани тестове с xUnit.
